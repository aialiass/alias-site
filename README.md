# alias-site

Landing di Alias, pubblicata su https://alias-ai.it tramite Vercel (deploy automatico a ogni push su `main`).

Pagine statiche, nessuna build: `index.html` (homepage) e `come-funziona.html`. Il font Bricolage Grotesque è incorporato nei file.

Da completare in `index.html`, nello script in fondo:
- `SIGNUP_ENDPOINT`: finché è vuoto il modulo di iscrizione non invia niente. Prima di attivarlo serve un'informativa privacy linkata dal modulo.
- l'indirizzo di contatto, oggi `[email da definire]`.
